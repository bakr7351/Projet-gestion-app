Comment utiliser

Ce calculateur permet de déterminer toutes les propriétés psychrométriques d'un point à partir de deux paramètres indépendants.

Exemples de combinaisons:
• Température sèche + Humidité relative
• Température sèche + Température humide
• Température humide + Humidité relative
• Température sèche + Enthalpie

Une fois calculé, le point sera affiché sur le diagramme psychrométrique avec toutes ses propriétés.
